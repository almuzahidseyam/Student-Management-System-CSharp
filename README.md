# Student Management System (C#)

A desktop application developed using **C#** and **Windows Forms (WinForms)** for the **Software Development Project-I (CCE 310)** course.

This application provides a comprehensive interface for managing student records, including adding, updating, viewing, and deleting student information efficiently.

## Features
- **Student Registration:** Add new students with detailed information (Name, ID, Department, Contact, etc.).
- **Record Management:** Update or delete existing student records.
- **Database Integration:** Securely stores and retrieves data using a relational database (Database scripts included).
- **User-friendly GUI:** Easy-to-navigate interface built with Windows Forms.

## Technology Stack
- **Language:** C#
- **Framework:** .NET Framework (Windows Forms)
- **Database:** SQL Server / MySQL (Refer to the database script folder)
- **IDE:** Visual Studio

## How to Run
1. Open Csharp_student_information_system.sln in **Visual Studio**.
2. Import the database script located in the database script folder into your database server.
3. Update the database connection string in the project settings/code if necessary.
4. Build and run the project (Press F5).
